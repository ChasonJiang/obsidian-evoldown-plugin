# Evoldown

为 Obsidian 添加 Evoldown 语法支持。支持 `#d`、`#e`、`#t`、`#v`、`#c` 五种自定义标签。

![Evoldown 效果预览](preview.png)

## 安装

要求 Obsidian 1.5.7 或以上。在 Releases 中下载 evoldown.zip并解压， 放入笔记库的 `.obsidian/plugins`文件夹下，在「设置 → 第三方插件」中启用 Evoldown。

升级时覆盖该文件夹，再重新启用插件。

## 语法

- `#d` 描述、`#e` 例子、`#t` 迁移、`#v` 验证：`#字母 标题 [引用标题]`
- `#c` 自定义标签：`#c 标签名称 标题 [引用标题]`

引用标题可省略；字段含空格时用英文引号包住。正文延续到下一个标题或文件末尾。

```markdown
#d 描述1
描述1的内容

#e 例子1 描述1
例子1的内容

#d 描述2 描述1
描述2的内容

#t 迁移1 描述2
迁移1的内容

#v 验证 描述2
验证的内容

#c 自定义标签 标题 迁移1
自定义标签的内容
```

## 使用

- 支持阅读视图和实时预览。在实时预览中，单击标题、类型图标或自定义标签即可编辑。
- 单击引用标题跳转到当前笔记的对应标题；同名时取第一个。
- 在「设置 → Evoldown」选择标题级别 H1–H6，默认 H6。
- 启用核心插件「大纲」后，自定义标题会按所选级别显示，支持点击定位。

## 开发

需要 Node.js 18 或以上，无需安装依赖。

```sh
npm test
npm run build
```

构建产物位于 `dist/evoldown/`。
